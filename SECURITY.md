# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 1.x | Yes |
| 0.2.x and earlier | No |

Security fixes are released for the latest stable 1.x version.

## Reporting a vulnerability

Do not report suspected vulnerabilities in a public issue.

Use GitHub's private vulnerability reporting form:

https://github.com/tikipiya/asyncx/security/advisories/new

Include the affected version, a minimal reproduction, expected impact, and any known
mitigation. Reports will be acknowledged and investigated on a best-effort basis.

After a fix is available, maintainers may publish a GitHub Security Advisory and a
patched release.
